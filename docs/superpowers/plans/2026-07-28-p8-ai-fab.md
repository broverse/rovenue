# P8 — AI FAB + App Store Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Free-text AI tree mutations from a builder FAB (propose→approve→client-side apply with revert) plus "From App Store" and "AI assist" start-modal tabs, all on the existing Rovi copilot framework.

**Architecture:** A shared pure `applyTreeOp` + validation service backs three producers (chat intent handler, iTunes import, one-shot generation) that all RETURN validated trees/ops — nothing server-side writes builderConfig (autosave race). The dashboard applies via the VM with a pre-apply snapshot and Revert. Rovi panel is reused; paywall tools load only on the builder route.

**Tech Stack:** Hono + Drizzle + AI-SDK (`streamText` tools, `generateObject`) + Zod (api), React + impair + react-query (dashboard), Vitest.

**Spec:** `docs/superpowers/specs/2026-07-28-p8-ai-fab-design.md` — read it first.

```ts
// shared/paywall/tree-op.ts
export type PaywallTreeOp =
  | { kind: "insert"; parentId: string; index: number; subtree: PaywallNode }
  | { kind: "replace"; nodeId: string; subtree: PaywallNode }
  | { kind: "remove"; nodeId: string }
  | { kind: "updateProps"; nodeId: string; patch: Record<string, unknown> }
  | { kind: "setLocalizations"; locale: string; entries: Record<string, string> };
export const paywallTreeOpSchema: z.ZodType<PaywallTreeOp>; // discriminated union on kind; subtree validated with the STRICT node schema
export class TreeOpError extends Error { constructor(public readonly code: "TARGET_NOT_FOUND" | "NOT_A_CONTAINER" | "INDEX_OUT_OF_RANGE" | "CANNOT_REMOVE_ROOT") }
/** Pure: returns a NEW config; throws TreeOpError on an invalid target. setLocalizations merges into config.localizations[locale]. Root stack cannot be removed/replaced-away. */
export function applyTreeOp(config: BuilderConfig, op: PaywallTreeOp): BuilderConfig;

// api/services/paywall-ai/validate-config.ts
export class GeneratedConfigError extends Error { constructor(public readonly issues: string[]) }
/** Strict builderConfigSchema parse + validateBuilderConfig save-tier check (isBlockingIssue). offeringPackageIds=[] is CORRECT here: FOREIGN_PACKAGE_ID is publish-tier, so an empty set cannot block a save-valid draft. Throws GeneratedConfigError listing codes. */
export function assertSaveValid(config: unknown): BuilderConfig;
```
